# חיבור MentorTAB · Desk לקבוצת וואטסאפ

הגשר הזה רץ על המחשב שלך (Windows), מחובר למספר וואטסאפ **ייעודי** כ"מכשיר מקושר",
ועונה בקבוצה כשמישהו כותב **טלבוט**. כל הודעה בקבוצה נשמרת בזיכרון של החוג.

## מה צריך לפני שמתחילים
1. **מספר ייעודי עם וואטסאפ** — סים שני / eSIM. טיפ: בטלפון עם שני סימים אפשר להתקין את
   אפליקציית **WhatsApp Business** על המספר השני, לצד הוואטסאפ הרגיל.
2. **המספר הייעודי מצורף לקבוצת החוג** (מנהל/ת הקבוצה מוסיף/ה אותו, כמו כל משתתף).
   מומלץ לשמור לו שם איש קשר: "טלבוט".
3. **Node.js** מותקן במחשב — https://nodejs.org → הורדת גרסת **LTS** → התקנה (Next עד הסוף).
   אחרי ההתקנה סגרי ופתחי מחדש את Git Bash.

## התקנה (פעם אחת)
ב-Git Bash:

    cd ~/Downloads
    git clone https://github.com/danyadotan/MentorTAB mentortab-live
    cd mentortab-live/whatsapp-bridge
    npm install

(`npm install` מוריד גם דפדפן מובנה — יכול לקחת כמה דקות.)

## הגדרה
פתחי את הקובץ `config.json` (בתיקייה `whatsapp-bridge`) ב-Notepad:

    {
      "apiUrl": "https://mentortab.onrender.com",
      "profile": "hiphop",
      "groupName": "",
      "trigger": "טלבוט"
    }

- **groupName** — שם קבוצת הוואטסאפ (מספיק חלק ממנו). אם לא בטוחה — השאירי ריק בהרצה
  הראשונה, והבוט ידפיס את רשימת הקבוצות שהמספר נמצא בהן; העתיקי משם.
- **profile** — החוג (`hiphop`, `first_robotics`...). כל חוג = קובץ בתיקייה `profiles/`.
- **trigger** — המילה שמפעילה תשובה. אפשר כמה, מופרדות בפסיק: `טלבוט,בוט`.

## הפעלה

    npm start

בהרצה הראשונה יופיע **קוד QR** (וגם יישמר כתמונה `qr.png` בתיקייה, אם בטרמינל הוא נראה שבור).
בטלפון של המספר הייעודי: **וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר** → סריקה.

כשמופיע `✅ Bot connected` — הבוט באוויר. בהפעלות הבאות לא צריך לסרוק שוב.

## בדיקה
מהטלפון האישי שלך, כתבי בקבוצה:

    טלבוט מאיזה גיל אפשר להצטרף?

## טוב לדעת
- **הבוט עונה רק כל עוד המחשב דלוק והחלון פתוח.** כדי שיעבוד 24/7 צריך שרת קטן קבוע
  (אפשר לעשות את זה בשלב הבא).
- תשובה ראשונה אחרי שקט ארוך יכולה לקחת עד דקה — השרת החינמי "מתעורר".
- **זיכרון:** בשרת החינמי הזיכרון של הקבוצה מתאפס כשהשרת נרדם (כ-15 דק' בלי פעילות).
  הידע הקבוע של החוג (מהפרופיל) תמיד נשאר. לזיכרון קבוע — שדרוג אחסון בהמשך.
- **תקנון וואטסאפ** לא מתיר אוטומציה של WhatsApp Web, ולכן משתמשים במספר ייעודי ובנפח מתון.
  חלופה תקנית לגמרי: Telegram.
- **התחברות נכשלה / הבוט התנתק:** מחקי את התיקייה `.wwebjs_auth` והריצי שוב `npm start`.
