# MentorTAB

Research-grade, in-the-moment support for FIRST mentors, without touching children's data.

MentorTAB helps mentors respond to common team challenges with short, research-grounded coaching guidance. The demo includes Hebrew, English, and Russian interfaces, with full RTL/LTR switching.

## What is included

- A self-contained `index.html` landing page and interactive Coaching Moment demo
- Hebrew, English, and Russian language options
- RTL support for Hebrew and LTR support for English and Russian
- Seven sample coaching scenarios grounded in established work on CBT, executive function, collaborative problem solving, sensory profiles, motivation, and temperament
- Privacy by architecture: the demo stores no children's data

## Run locally

Open `index.html` in a modern browser. No build step or server is required.

## Privacy

MentorTAB is designed to support mentors without collecting or storing children's personal data. The included scenarios and answers are prewritten demonstrations and are not clinical advice or diagnosis.
